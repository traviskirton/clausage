There are dozens of ways to watch your Claude limits, and several are good. The right one depends on where you already look: the Claude settings page, your terminal, your menu bar or your browser. Here’s an honest rundown, including when to pick something other than Clausage.

Do you need a tracker at all?

Maybe not. Settings → Usage on claude.ai shows every limit and when it resets, and it’s free and always right. If you hit a limit once a month, that page is enough.

A tracker earns its place when you hit limits often, or start big tasks without knowing whether there’s room. The value is seeing it without going to look.

If you live in the terminal

Start with what’s built in: Claude Code’s /usage shows your plan usage and what’s driving it. claude-hud puts usage in the status line, so it’s always under your cursor. ccusage is the long-standing choice for token and cost reports. All three stay inside Claude Code, which is the point if that’s where you work.

If you want it in the menu bar

Menu bar apps show your limits whether or not Claude is open, which matters if you also use Claude in the browser or desktop app. CodexBar is the pick if you use Codex, Cursor or other tools too: one app for all of them, with a large community. Claude Usage Tracker has the most settings of the Claude-only apps. Usage4Claude draws pace as a chart.

Where Clausage fits

  • Quiet by default. Under 85% it’s just a bar. Past that it gives a clock time, like Out ~Mon 9:40 PM, instead of a percentage to work out.
  • Pace on every bar. A tick shows where an even pace would put you now, so “am I OK for the week?” is one glance. (How pace works)
  • Any Claude plan, Claude Code optional. It reads the same usage page you’d check yourself, so it works for chat and Cowork too.
  • Private. No analytics and no server. The optional Claude Code scan keeps totals only, never prompts or code. Open source, so you can check.
  • Claude only. If you want other providers in the same place, CodexBar is the better fit.
